# ALST website

One-page website for ALStrade Consulting Sàrl (alstrade.ch).

- `index.html` – the whole site (Home and Get in touch views, switched with `#contact`)
- `assets/` – logo and photos

Open `index.html` in a browser to view it. To publish, upload `index.html` and `assets/` to any static host.

The contact form posts to a form service: set `FORM_ENDPOINT` in `index.html` (e.g. a Formspree URL) to receive messages by email.
